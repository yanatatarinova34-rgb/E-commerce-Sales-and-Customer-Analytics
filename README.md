# E-commerce-Sales-and-Customer-Analytics
SQL-анализ продаж, товарных категорий и клиентской базы
Инструменты: SQL, SQLite, DBeaver, DataLens
Датасет: E-Commerce Sales & Customer Analytics Dataset

О проекте: 
В рамках проекта проведен анализ интернет-магазина за 2024 год.
Цель анализа - исследовать динамику продаж, структуру клиентской базы и вклад товарных категорий  и отдельных товаров в выручку. В работе использованы 4 связанные таблицы (customers, orders, order_items, products)
Основные связи:
customers.customer_id → orders.customer_id
orders.order_id → order_items.order_id
products.product_id → order_items.product_id
Структура таблиц и внешние ключи настроены в SQLite. В order_items используется составной ключ order_id + product_id.

# Бизнес-вопросы
В рамках проекта были поставлены следующие вопросы:
## Продажи
Как изменялись продажи в течение 2024 года?
Как менялись выручка, количество заказов и средний чек?
Как распределяются заказы по статусам?
## Категории и товары
Какие категории формируют наибольшую выручку?
Какие категории имеют больший средний доход на заказ?
Какие товары являются основными источниками выручки?
Насколько выручка категорий зависит от нескольких ключевых товаров?
## Клиенты
Как распределяются клиенты по количеству заказов?
Какую роль в выручке играют повторные покупатели?
Как отличаются клиенты с одним и несколькими заказами?
Какова продолжительность периода между первой и последней покупкой?
# Основные показатели
Для расчёта основной выручки использовались только заказы со статусом Completed.
По результатам анализа: Completed-заказы = 132, Проданные единицы =	433, Выручка = 28 767, Returned-заказы =	11, Canceled-заказы =	10
Количество и продажи по статусам были отдельно проверены перед расчётом основных показателей.
Returned и Canceled заказы не включались в основную выручку, чтобы не смешивать завершённые продажи с операциями, которые впоследствии были возвращены или отменены.
# Анализ клиентской базы
Клиенты были разделены на три группы: клиенты без заказов, клиенты с одним заказом, повторные покупатели — два и более заказа. Исходный анализ показал: 15 клиентов не совершили ни одного заказа, 39 клиентов совершили один заказ, 246 клиентов совершили два и более заказов. Для клиентов с двумя и более заказами среднее количество заказов составило 3,91, максимум — 9 заказов.
Клиентская база в большей степени представлена повторными покупателями. Поэтому для бизнеса имеет смысл отдельно отслеживать повторные покупки и вклад таких клиентов в выручку.
# Анализ продаж
Для анализа динамики были рассчитаны: количество заказов, количество проданных единиц, выручка, средний чек.
Расчёты выполнялись на уровне месяца с использованием STRFTIME() для группировки дат.
Для основной аналитики выручка рассчитывалась только по статусу Completed.
# Анализ категорий
По результатам анализа Body занимает первое место по выручке — 8 295. Makeup практически сопоставим с Body по выручке — 8 149, несмотря на меньшее количество заказов.Hair имеет наибольшее количество заказов — 41, однако по выручке занимает третье место. Это показывает, что количество заказов само по себе не определяет размер выручки: важен также доход на один заказ. Такой расчёт уже есть в SQL-кейсе.
# Анализ товаров
Для каждой категории были рассчитаны: количество проданных единиц, выручка, доля товара в выручке категории, место товара внутри категории.
Также был рассчитан TOP-3 товаров по каждой категории с использованием оконной функции ROW_NUMBER().
По текущему анализу наиболее высокая концентрация наблюдается в категории Skin:
TOP-3 товара — 63,66% выручки категории;
Body — 50,61%;
Makeup — 38,41%;
Hair — 34,53%.
Категории отличаются не только объёмом продаж, но и структурой выручки. В Skin значительная часть выручки приходится на небольшое количество товаров, тогда как в Makeup и Hair продажи распределены более равномерно.
# Повторные покупки
Клиенты были разделены по количеству заказов, после чего отдельно рассчитана выручка, относящаяся к Completed заказам.
По текущему анализу средняя выручка на одного повторного покупателя после исключения Returned и Canceled операций составила 106,45.
Дополнительно была рассчитана продолжительность клиентской активности:
first purchase → last purchase
Для этого использовалась разница дат через julianday().
Повторные покупки являются отдельным важным направлением анализа клиентской базы. Для дальнейшей работы с клиентами можно дополнительно использовать RFM-сегментацию.

# Итог
В рамках проекта проведён анализ продаж интернет-магазина за 2024 год: от структуры клиентской базы и динамики выручки до анализа категорий, отдельных товаров и повторных покупок. Основные результаты: определены показатели Completed-продаж, выявлена структура клиентской базы, определены категории с наибольшей выручкой, проведён анализ TOP товаров, оценена концентрация выручки внутри категорий, исследован вклад повторных покупателей, рассчитана продолжительность клиентской активности, подготовлена основа для визуального аналитического дашборда.
