# E-commerce-Sales-and-Customer-Analytics
SQL-анализ продаж, товарных категорий и клиентской базы
Инструменты: SQL, SQLite, DBeaver, DataLens
Датасет: E-Commerce Sales & Customer Analytics Dataset

О проекте: 
В рамках проекта проведен анализ интернет-магазина за 2024 год.
Цель анализа - исследовать динамику продаж, структуру клиентской базы и вклад товарных категорий  и отдельных товаров в выручку. В работе использованы 4 связанные таблицы (customers, orders, order_items, products)
